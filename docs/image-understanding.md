# Фотографии и Vision

## Возможности

Агент «Алиса Селезнёва» принимает фотографию из браузера или Android и отвечает
на связанный вопрос. Основной сценарий — снимок ночного неба. Алиса также может
объяснить другое безопасное содержимое снимка, но не определяет личности людей,
адрес, здоровье или другие чувствительные сведения.

Фото обрабатывается одноразово. В историю сохраняются вопрос ребёнка и текстовый
ответ, но не файл и не base64. Очистка чата поэтому не управляет фотографиями:
удалять уже нечего.

## Настройка

В админке откройте «Настройки → Фотографии от Леры»:

1. Выберите `OpenAI-compatible`.
2. Укажите Vision-модель.
3. При необходимости задайте отдельные Base URL и API-ключ. Пустые значения
   используют LLM Base URL и LLM-ключ.
4. Сохраните настройки и перезапустите Gateway.

Для текущего Groq OpenAI-compatible endpoint подходит модель
`qwen/qwen3.6-27b`. Model ID остаётся настройкой:
провайдер может заменить или отключить preview-модель.

Эквивалентная конфигурация:

```dotenv
FAMILY_AI_VISION_PROVIDER=openai_compatible
FAMILY_AI_VISION_MODEL=qwen/qwen3.6-27b
FAMILY_AI_VISION_BASE_URL=https://api.groq.com/openai/v1
# Не задавайте, чтобы использовать FAMILY_AI_OPENAI_API_KEY:
FAMILY_AI_VISION_API_KEY=
FAMILY_AI_VISION_MAX_IMAGE_BYTES=10485760
```

## API

```http
POST /v1/vision/{conversation_id}/turn
Content-Type: multipart/form-data

file=<JPEG, PNG или WebP>
question=Алиса, какое это созвездие?
```

Ответ — обычный `MessageResponse`. Максимальный размер по умолчанию — 10 MiB;
его можно изменить в админке в пределах 1–14 MiB. Публичный манифест агента
возвращает фактический лимит в `image_upload_max_bytes`, поэтому клиенты не
дублируют серверную настройку.

Веб-клиент отправляет исходный JPEG, PNG или WebP, если тот помещается в лимит.
Более крупное изображение уменьшается в браузере и кодируется в JPEG. Ошибки
`413`, `415` и `422` показываются отдельно, а не маскируются общим сообщением.
Android перед отправкой уменьшает изображение до 2048×2048 и качества JPEG 88.

Gateway не записывает изображение, имя файла или base64. Для диагностики в
журнал попадают только MIME-тип, размер и первые 16 символов SHA-256. Этого
достаточно, чтобы сравнить мобильную и браузерную версии одного фото, не
сохраняя содержимое.

Vision-провайдер получает явное указание не считать один загруженный кадр
коллажем или повторяющимися копиями без однозначно видимых границ. Это снижает
риск уверенных ложных выводов модели о структуре фотографии.

## Ограничения астрономии

Телефон часто не фиксирует слабые звёзды, и один рисунок ярких точек может
совпадать с несколькими участками неба. Для более точного объяснения родитель
может помочь назвать:

- дату и примерное время;
- город или область без точного адреса;
- направление взгляда: север, юг, восток или запад;
- положение камеры относительно горизонта.

Никогда нельзя смотреть на Солнце глазами, в бинокль, телескоп или через камеру
без специального сертифицированного солнечного фильтра.
