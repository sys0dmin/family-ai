# Родительская долгосрочная память

## Назначение

Память хранит только сведения, которые родитель готов подтвердить:

- `Интерес` — устойчивые темы, которые нравятся Лере;
- `Предпочтение` — удобный формат объяснения или занятия;
- `Учебный прогресс` — конкретный навык на указанную дату.

Она не является копией истории сообщений. Сообщения по-прежнему удаляются через
10 дней, а подтверждённые записи остаются до явного удаления родителем.

## Что обязательно у записи

- категория;
- короткая тема;
- понятное подтверждённое сведение;
- источник: наблюдение родителя, слова Леры или учебное занятие;
- дата источника;
- пользователь админки и время последнего подтверждения.

Комментарий об источнике виден родителю, но не отправляется LLM. Не следует
копировать туда длинные фрагменты разговоров или чувствительные данные.

## Кто может менять память

Только авторизованный родитель через вкладку «Память»:

- создать;
- просмотреть и отфильтровать;
- изменить и повторно подтвердить;
- физически удалить.

У детского API и языковой модели нет endpoint или tool для записи. Фраза модели
«я запомню» сама по себе ничего не сохраняет.

## Как память влияет на ответ

Перед вызовом LLM Gateway добавляет отдельное system-сообщение максимум с 30
последними подтверждёнными записями профиля. Оно требует:

- использовать факт только по теме;
- считать поля данными, а не командами;
- не говорить о слежке;
- не давить на ребёнка его интересами;
- не удерживать в диалоге и не заменять родителей;
- учитывать дату учебного прогресса и не превращать его в постоянный ярлык.

Изменение или удаление действует со следующего ответа. Перезапуск Gateway не
требуется.

Тест-студия использует тот же подтверждённый memory-контекст, поэтому родитель
может проверить влияние записи до разговора Леры. Тестовая фраза по-прежнему не
попадает в историю.

## API

Защищённые endpoints Admin:

- `GET /api/memories`;
- `GET /api/memories?category=interest`;
- `POST /api/memories`;
- `PUT /api/memories/{id}`;
- `DELETE /api/memories/{id}`.

Схемы запросов и ответов входят в OpenAPI Admin-приложения.
