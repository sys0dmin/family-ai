# Калибровка STT под речь Леры

Эта памятка описывает полный цикл локальной калибровки `faster-whisper` на
`family-ai-speech`. Никакие записи не нужно вручную загружать, скачивать или
удалять.

## Что делает калибровка

Один запуск собирает 15 временных WAV:

- 12 коротких фраз с заранее известным текстом;
- 3 записи тишины, чтобы проверить ложные распознавания.

Затем Speech Service прогоняет каждый образец через шесть конфигураций:

| VAD | Beam size |
|---|---:|
| включён | 1 |
| включён | 3 |
| включён | 5 |
| выключен | 1 |
| выключен | 3 |
| выключен | 5 |

Всего получается 90 локальных распознаваний. Для каждой конфигурации считаются
точность слов, доля правильно отброшенной тишины, среднее время, P95 и средняя
уверенность модели. Рекомендация выбирается сначала по точности, затем по
отбрасыванию тишины и только потом по скорости.

Калибровка не меняет production-настройки автоматически. Это намеренно:
результат одного замера должен быть проверен родителем, а изменение
`/etc/family-ai/speech.env` и перезапуск службы остаются явной административной
операцией.

## Перед началом

1. Установите на телефон свежий APK с экраном калибровки.
2. Подключите телефон к домашней сети, в которой доступен Gateway.
3. Один раз откройте приложение и убедитесь, что виден экран персонажей.
4. Выберите обычную тихую комнату. Не нужна студийная тишина: полезнее измерить
   привычные домашние условия.
5. Положите телефон примерно там, где Лера обычно им пользуется. Не подносите
   микрофон вплотную ко рту.
6. На время записи не запускайте голосовой диалог на другом устройстве.

## Как запустить

1. Откройте админку.
2. Войдите и перейдите на вкладку «Тест-студия».
3. Найдите блок «Калибровка речи Леры».
4. Нажмите «Начать калибровку».
5. Откройте Android-приложение или вернитесь на экран выбора персонажей.
   Приложение проверяет активную сессию примерно раз в 10 секунд и само откроет
   экран «Настраиваем слух».

Одновременно может существовать только одна активная сессия. Повторное нажатие
в админке не создаёт второй набор.

## Что делает Лера

Для каждой обычной фразы:

1. приложение само произносит задание;
2. Лера нажимает большую круглую кнопку с микрофоном;
3. спокойно повторяет услышанную фразу;
4. нажимает ту же кнопку ещё раз.

Запись автоматически остановится через 12 секунд, если второе нажатие забыто.
Для трёх заданий с тишиной нажимать ничего не нужно: приложение попросит
помолчать и само запишет три секунды окружающего звука.

Читать текст не требуется. Фраза показана на экране только как дополнительная
подсказка родителю; основной сценарий построен на озвучке, крупной пиктограмме и
одной кнопке.

## Если что-то прервалось

- Если не проигралось задание или не отправилась запись, нажмите «Ещё раз».
- Если приложение закрыли, уже принятые образцы остаются в локальной сессии
  Speech Service. Снова откройте экран персонажей — приложение продолжит с
  первого отсутствующего задания.
- Если все 15 файлов успели отправиться, но команда анализа не дошла из-за
  разрыва сети, приложение повторно запустит анализ при следующем открытии.
- Если продолжать не нужно, нажмите в админке «Отменить и удалить записи».
  Повторный запуск начнёт новый чистый набор.
- Незавершённая сессия истекает через 24 часа. Фоновая уборка Speech Service
  удалит её WAV даже без открытой админки.

## Что происходит после последней фразы

Android отправляет команду завершения и показывает экран успеха. После этого
телефон можно закрыть: дальнейший анализ идёт только на `family-ai-speech`.

На J3710 ожидаемое время — примерно 15–25 минут. Все шесть конфигураций делят
одну очередь с обычным STT/TTS. Блокировка освобождается между отдельными
прогонами, поэтому срочный обычный запрос сможет вклиниться, но голосовые ответы
во время калибровки могут приходить медленнее. Загрузка CPU около 100% ожидаема.

Админка обновляет:

- `Образцы` — сколько из 15 файлов принято;
- `Анализ` — сколько из 90 прогонов закончено;
- таблицу уже рассчитанных конфигураций;
- итоговую рекомендацию VAD и beam size.

## Как читать результат

- `Точность` — совпадение распознанных слов с известными фразами. Больше лучше.
- `Тишина` — сколько тихих образцов не превратились в выдуманный текст. Больше
  лучше.
- `Среднее` — средняя задержка одного STT-прогона. Меньше лучше.
- `P95` — время, быстрее которого завершились 95% прогонов. Оно лучше показывает
  неприятные долгие ожидания, чем одно среднее.
- `Рекомендация` — лучший баланс по зафиксированному правилу выбора.

Точность считается через расстояние между последовательностями слов. Если
ребёнок произнёс правильные слова в другом порядке, метрика снизится, даже
когда смысл и сами слова распознаны верно. Поэтому результат нужно читать как
строгое совпадение с контрольной фразой, а не как процент понятности речи.

Не применяйте результат, если во время большей части записи рядом громко говорил
другой человек, работал телевизор или Лера намеренно не повторяла задания. В
таком случае отмените/запустите новый сеанс и получите чистый замер.

## Как применить рекомендацию

Допустим, админка показала `VAD вкл., beam 3`.

1. В том же блоке «Калибровка речи Леры» выберите beam `3`.
2. Включите переключатель VAD.
3. Нажмите «Сохранить и перезапустить Speech» и подтвердите действие.
4. Дождитесь сообщения «Speech перезапущен, настройки подтверждены». Обычно
   загрузка моделей на J3710 занимает около 15 секунд.
5. Сделайте несколько обычных голосовых запросов Леры и сравните задержку и
   число повторов.

Админка записывает только beam/VAD в отдельный runtime-конфиг и проверяет
значения уже в новом процессе. Она не имеет доступа к остальным переменным,
секретам или произвольным systemd-службам.

Если Admin control ещё не установлен или админка недоступна, остаётся ручной
аварийный способ. Подключитесь к Speech, откройте
`/etc/family-ai/speech.env` с правами `sudo` и установите:

```dotenv
FAMILY_AI_SPEECH_STT_VAD_FILTER=true
FAMILY_AI_SPEECH_STT_BEAM_SIZE=3
```

Для `VAD выкл.` используйте `false`, затем выполните:

```bash
sudo systemctl restart family-ai-speech
sudo systemctl status family-ai-speech --no-pager
```

Не меняйте одновременно модель, порог уверенности и VAD/beam: иначе будет
непонятно, какое изменение помогло.

только из-за волнения или перестановки отдельных слов не требуется.

## Приватность и автоматическое удаление

- Android создаёт WAV во временном каталоге приложения и удаляет файл сразу
  после чтения.
- Gateway только проксирует байты; он не пишет калибровочные WAV на диск и не
  добавляет их в историю сообщений.
- Speech Service хранит файлы в
  `/var/lib/family-ai-speech/calibration/<случайный-id>/`.
- Идентификаторы сессии и файлов случайные; имена ребёнка в пути нет.
- Распознавание выполняется локально. Калибровочные WAV не отправляются LLM,
  облачному STT, Git или внешней аналитике.
- Каталог с WAV удаляется после успешного анализа, ошибки, ручной отмены,
  перезапуска во время анализа либо максимум через 24 часа.
- После удаления остаются только агрегированные проценты и времена без аудио и
  расшифровок.

Для необязательной проверки после завершения:

```bash
find /var/lib/family-ai-speech/calibration \
  -mindepth 1 -maxdepth 1 -type d -print
```

Команда не должна показать каталог завершённой сессии. Выполнять её после
каждого запуска не требуется.

## Диагностика

Статус служб:

```bash
sudo systemctl status family-ai-speech family-ai-gateway family-ai-admin \
  --no-pager
```

Последние сообщения Speech Service:

```bash
sudo journalctl -u family-ai-speech -n 100 --no-pager
```

Типовые ситуации:

- `Speech Service недоступен` — проверить службу, порт `8010` и bearer-ключ
  между Gateway и Speech;
- приложение не открыло экран — вернуться к выбору персонажей, подождать
  10 секунд и проверить доступность Gateway;
- анализ стоит на одном числе — посмотреть очередь и CPU во вкладке
  «Инфраструктура»; один тяжёлый прогон на J3710 может занимать заметное время;
- статус `Ошибка` — WAV уже удалены; начать новый сеанс после проверки журнала;
- сессия `Отменена` — начать новую, старые файлы не используются.
