# Дополнительные пациенты Доктора Пульса

В каталог добавлены два самостоятельных случая:

- `bunny_tired` — зайчик Снежок после долгой прогулки;
- `puppy_afraid` — щенок Бублик, который волнуется перед осмотром.

У каждого пациента собственные настроение, жалоба, начальные показатели и реакции на заботу. Сценарии доступны через общий API каталога, поэтому появляются в вебе и Android без дублирования интерфейсной логики.
