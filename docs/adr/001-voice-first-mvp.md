# Голосовой интерфейс — основной сценарий MVP

## Status

Accepted

## Context

Основной пользователь — Лера, шесть лет, говорит по-русски и ещё не читает связный текст. Matrix и обычный текстовый чат требуют навыков чтения и создают лишнюю сложность.

## Decision

Основной интерфейс MVP — голосовой PWA для Android-планшета. Диалог строится как push-to-talk: ребёнок удерживает кнопку, говорит и получает короткий озвученный ответ. Текстовый API проектируется одновременно, но его интерфейс реализуется позднее. Matrix не входит в MVP и может быть добавлен как транспортный адаптер.

## Alternatives

- Matrix/Element как основной интерфейс: отклонено, потому что это взрослый интерфейс и он не подходит ребёнку, который не читает.
- Постоянно слушающий агент или wake word: отклонено ради приватности и предсказуемости записи.

## Consequences

Положительные последствия: MVP соответствует возрасту пользователя и проверяет главный продуктовый сценарий.

Отрицательные последствия: нужны STT, TTS, HTTPS в домашней сети и тестирование на реальном Android-устройстве.
