# FastAPI для HTTP-слоя AI Gateway

## Status

Accepted

## Context

Gateway предоставляет внутренний REST API для голосового PWA и будущих транспортных адаптеров. Контракты должны валидироваться, документироваться в OpenAPI и оставаться независимыми от AI provider.

## Decision

HTTP-слой Gateway реализуется на FastAPI. Pydantic используется для входных и выходных моделей, а Uvicorn — как ASGI-сервер. Конфигурация приложения загружается из переменных окружения с помощью `pydantic-settings`.

## Alternatives

- Flask: отклонён, потому что OpenAPI и валидация потребовали бы дополнительной ручной интеграции.
- Django: отклонён как избыточный для API-сервиса без серверных HTML-шаблонов.

## Consequences

Положительные последствия: типизированные контракты, автоматическая OpenAPI-документация и простые тесты API.

Отрицательные последствия: Gateway зависит от FastAPI, Pydantic и ASGI-сервера; эти зависимости изолированы в HTTP-слое.
