# Краткое хранение транскриптов без резервного копирования MVP

## Status

Accepted

## Context

Для контекста разговора и статистики нужна история, но проект обрабатывает данные ребёнка. Семья выбрала хранение истории десять дней и отказалась от резервных копий на этапе MVP.

## Decision

Исходные аудиозаписи не сохраняются. Транскрипты ребёнка и ответы агента хранятся в PostgreSQL десять дней и затем автоматически удаляются. Агрегированная статистика без текста сохраняется отдельно. Ceph используется для рабочего реплицируемого хранилища, но резервные копии не создаются.

## Alternatives

- Постоянная история: отклонена ради минимизации данных ребёнка.
- Сохранение аудио: отклонено, так как оно не нужно для сценария MVP.
- Резервные копии БД: отложены по решению семьи.

## Consequences

Положительные последствия: минимизация чувствительных данных и простая эксплуатация.

Отрицательные последствия: история может быть безвозвратно потеряна при логической ошибке, удалении или отказе всего кластера; удалённые данные нельзя восстановить.
