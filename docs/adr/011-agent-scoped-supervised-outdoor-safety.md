# Агентское разрешение на походную безопасность под надзором

## Status

Accepted

## Context

Базовый safety filter блокирует вопросы об огне, спичках и ножах. Для детского походного гида полный отказ неполезен: ребёнку нужно объяснить, как подготовиться и какую часть опасного действия выполняет родитель. Глобальное ослабление фильтра снизило бы безопасность остальных агентов.

## Decision

Добавить в конфигурацию агента отдельный allowlist `permissions`. Первое разрешение — `supervised_outdoor_safety`. Оно даёт агенту «Мурка» право обсуждать костёр, спички, нож и заточку в контексте похода. Остальные агенты сохраняют исходные запреты.

Gateway передаёт permissions во входную и выходную safety-проверку. Для агента с таким разрешением ответ детерминированно дополняется требованием участия родителей, если модель его забыла. Это правило не зависит от prompt.

Для четырёх особо чувствительных сценариев — разведения костра, заточки ножа, проверки найденного гриба или ягоды — Gateway возвращает проверенную полезную инструкцию. Это исключает нестабильные роли, в которых модель может случайно поручить ребёнку опасную часть. Остальные темы о природе остаются свободным диалогом с моделью.

Обучающее обсуждение опасностей дикой природы разрешается: растений, грибов, ягод, клещей, змей, животных, воды, погоды, рельефа и других походных рисков. Общие запросы о получении или использовании яда остаются заблокированными. Агент никогда не определяет найденный вид или съедобность по описанию или фотографии. Для проверки фактов агенту доступен провайдер-нейтивный веб-поиск.

## Alternatives

- Убрать опасные слова из общего фильтра: отклонено, потому что это ослабит всех агентов.
- Положиться только на prompt: отклонено, потому что модель может забыть напоминание о взрослом.
- Блокировать любой ответ о ноже или костре: отклонено, так как обучающая альтернатива с родителями полезнее чистого отказа.

## Consequences

Положительные: ребёнок получает полезный ответ вместо отказа; опасная часть действия явно отдана взрослому; permissions можно расширять без зашивки agent ID.

Отрицательные: safety filter становится контекстным и требует тестов на каждое разрешение; ответы Мурки намеренно часто напоминают о родителях.
