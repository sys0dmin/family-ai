# Provider interface для AI-функций

## Status

Accepted

## Context

MVP использует OpenAI для распознавания речи, генерации ответа и синтеза речи. В будущем семья может перейти на локальные или другие облачные решения.

## Decision

Gateway зависит от внутреннего Provider interface с нормализованными операциями `transcribe_audio`, `generate_response` и `synthesize_speech`. OpenAI SDK используется только в реализации OpenAI provider. Контракт включает модели запросов, ответов, ошибок и сведений об использовании.

## Alternatives

- Вызывать OpenAI SDK непосредственно из роутеров и сервисов Gateway: отклонено из-за сильной связанности.
- Создать отдельный микросервис для каждого provider уже в MVP: отклонено как преждевременное усложнение.

## Consequences

Положительные последствия: поставщик заменяется конфигурацией и новой реализацией адаптера; Gateway легко тестировать с fake provider.

Отрицательные последствия: в начале требуется поддерживать собственные модели и адаптер вместо прямого вызова SDK.
