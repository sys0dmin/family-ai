# Защищённый просмотр истории для родителей

## Status

Accepted

## Context

Первоначально родительский интерфейс должен был показывать только агрегированную
статистику. На практике просмотр и диагностика разговоров через ручные SQL-запросы
неудобны. Родителю нужен понятный способ увидеть недавние расшифровки, проверить
качество распознавания и понять интересы ребёнка.

## Decision

В отдельной вкладке защищённой админки показывать сообщения за период хранения:

- read-only список диалогов с пагинацией и поиском;
- текстовые реплики ребёнка и ответы AI;
- активность по дням, количество разговоров и среднее время ответа;
- частые вопросы, вычисляемые из уже сохранённых сообщений;
- никакого хранения или отображения исходного аудио.

API истории остаётся частью админки, защищается тем же HTTP Basic доступом и не
публикуется через детский Gateway API. Содержимое сообщений не записывается в
технические логи. Интерфейс выводит текст только безопасными DOM-операциями.

## Alternatives

- Оставить просмотр только через PostgreSQL: отклонено как неудобное и
  небезопасное для повседневного использования.
- Показывать только агрегаты: отклонено, потому что они не позволяют проверить
  ошибки STT и качество конкретного ответа.
- Создать отдельное аналитическое хранилище: отклонено как преждевременное для
  домашнего объёма и окна хранения 10 дней.

## Consequences

Положительные последствия: родитель получает понятный аудит разговоров, поиск и
аналитику без доступа к БД; новая схема данных не требуется.

Отрицательные последствия: админка теперь обрабатывает чувствительные тексты и
должна оставаться доступной только в доверенной сети с обязательной
аутентификацией. При появлении внешнего доступа потребуется HTTPS и усиленная
аутентификация.
