# Доступ к MVP только из домашней сети

## Status

Accepted

## Context

Проект предназначен для одной семьи и не требует доступа извне. Детский интерфейс должен открываться без PIN-кода и логина.

## Decision

Gateway и PWA доступны только в доверенной домашней LAN. Внешний доступ, публичный DNS и проброс портов не создаются. Детская страница использует фиксированный профиль Леры без аутентификации. Административная статистика располагается на отдельном защищённом маршруте.

## Alternatives

- Публичный доступ с учётными записями: отклонён как ненужный для MVP и увеличивающий поверхность атаки.
- PIN-код на детской странице: отклонён по желанию семьи.

## Consequences

Положительные последствия: минимальный детский UX и меньшая внешняя поверхность атаки.

Отрицательные последствия: любой пользователь доверенной LAN может начать разговор от имени Леры. Безопасность зависит от защиты домашней сети.
