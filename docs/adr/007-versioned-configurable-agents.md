# Версионируемые конфигурации AI-агентов

## Status

Accepted

## Context

Системный prompt агента «Учитель-друг» был строкой в Python-коде. Изменение
личности требовало новой сборки и развёртывания Gateway. Кроме того, один агент
не покрывает разные детские сценарии: объяснение, исследование, сказки и обучение
через наводящие вопросы.

## Decision

Хранить метаданные агентов и опубликованные версии их personality prompt в
PostgreSQL. Каждый диалог закрепляется за одним агентом и конкретной опубликованной
версией через `agent_id` и `agent_revision_id`.
Переключение агента создаёт новый диалог и не смешивает системные инструкции и
контекст разных персонажей. Публикация новой версии влияет только на новые
диалоги; уже начатый разговор остаётся воспроизводимым.

Gateway загружает активную версию через `AgentRepository`. Код диалога не знает,
где хранится конфигурация, и зависит только от доменного контракта агента.

Обязательный child-safety baseline хранится в PostgreSQL как отдельная
версионируемая глобальная конфигурация и добавляется перед personality prompt.
Защищённая админка создаёт новую неизменяемую ревизию и сразу публикует её для
всех агентов. При отсутствии строки конфигурации Gateway использует безопасный
baseline из кода.

Редактируемый baseline влияет только на инструкции модели. Существующий
программный safety pipeline, permissions и детерминированные фильтры остаются
обязательными и не могут быть отключены через prompt.

Начальный набор:

- `teacher_friend` — Учитель-друг;
- `scientist` — Почемучка;
- `storyteller` — Сказочник;
- `socrates` — Подумай сама.
- `musician` — Нотка, с явно разрешённым инструментом распознавания мелодий.
- `outdoor_guide` — Мурка, походница и гид по дикой природе.
- `tech_guide` — Байтик, детский гид по ИТ, инфраструктуре и искусственному интеллекту.

Разрешения safety хранятся в `permissions` отдельно от `tools`. Prompt агента не может сам выдать себе разрешение.

Список инструментов хранится в метаданных агента. Бизнес-логика выполнения остаётся в Gateway; prompt не может сам выдать себе новое разрешение.

## Alternatives

- Хранить prompts в Python: отклонено, потому что агент является конфигурацией.
- Хранить только YAML/Markdown на сервере: отклонено для runtime-редактирования,
  версионирования и безопасного отката через админку.
- Разрешить ребёнку вводить произвольный prompt: отклонено по причинам
  безопасности и возрастной уместности.

## Consequences

Положительные последствия: агенты и общий baseline меняются без новой версии
кода, имеют историю; детский интерфейс получает безопасный allowlist; контексты
не смешиваются; программные ограничения не зависят от редактируемого текста.

Отрицательные последствия: появляется новая миграция и административная логика
публикации; Gateway зависит от доступности конфигурации в БД. Для отказоустойчивого
запуска сохраняется идентификатор агента по умолчанию, но отсутствие активной
версии считается ошибкой конфигурации и не маскируется скрытым prompt из кода.
