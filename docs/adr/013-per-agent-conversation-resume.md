# Возобновление диалогов отдельно для каждого агента

## Статус

Принято

## Контекст

Ребёнок свободно переключается между персонажами. Если при каждом переключении
создавать новый разговор, агент забывает недавнюю беседу. Единая история для
всех персонажей, напротив, смешивает роли, промпты и разрешения разных агентов.
Хранить идентификаторы текущих разговоров только в браузере ненадёжно: состояние
теряется при смене устройства или очистке данных сайта.

## Решение

Gateway является источником состояния и возвращает последний разговор отдельно
для пары «профиль ребёнка + агент». Возобновляются только разговоры, активные в
пределах настроенного окна хранения сообщений. Детскому интерфейсу возвращаются
не более 100 последних реплик.

Разговор остаётся привязан к той ревизии агента, с которой был создан. Явное
действие «начать заново» создаёт пустой разговор с текущей опубликованной
ревизией. Оно требует повторного визуального нажатия и не удаляет старую историю.

## Альтернативы

- Всегда создавать новый разговор при выборе агента: отклонено из-за потери
  полезного краткосрочного контекста.
- Передавать одну общую историю всем агентам: отклонено из-за смешивания ролей,
  правил безопасности и контекстов.
- Хранить текущие идентификаторы только в `localStorage`: отклонено, потому что
  браузер не должен быть источником истины для серверной истории.
- Автоматически переводить старый разговор на новую ревизию агента: отклонено,
  так как это меняет поведение посреди беседы и ухудшает воспроизводимость.

## Последствия

Положительные: персонажи помнят собственные недавние беседы, переключение не
смешивает их контекст, а родитель сохраняет полную историю в рамках retention.

Отрицательные: появляется дополнительный API чтения и запрос при выборе
персонажа. Очень длинная беседа показывается частично; полный просмотр остаётся
в родительской админке.
