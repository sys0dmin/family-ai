# Детерминированная игровая больница

## Status

Accepted

## Context

Новый агент должен поддерживать понятную шестилетнему ребёнку игру в больницу:
показывать вымышленного пациента, декоративный монитор, игровые показатели и
отмеченные процедуры. Свободная генерация назначений языковой моделью может
случайно превратить игру в совет по самолечению.

Обычный `ActivitySession` хранит только номер шага и не подходит для независимых
действий, показателей и идемпотентного журнала процедур.

## Decision

Создать внутри Gateway отдельный bounded context `clinic`.

- Агент `clinic_guide` остаётся версионируемой конфигурацией.
- `ClinicCaseCatalog` загружает конечные сценарии из JSON и строго валидирует их.
- `ClinicGameService` единолично изменяет показатели и принимает процедуры.
- LLM получает снимок игры только как контекст для разговора и не может менять
  состояние, назначать лекарства или добавлять действия.
- Сессия привязана к разговору, имеет TTL 24 часа и удаляется общим retention.
- Повтор процедуры идемпотентен.
- Реальная жалоба во время игры ставит её на паузу и возвращает фиксированную
  просьбу немедленно позвать взрослого.
- Клиенты всегда показывают, что монитор игровой и ничего не измеряет.

## Alternatives

- Хранить состояние в prompt или истории: отклонено как недетерминированное.
- Расширить линейные приключения произвольным JSON-состоянием: отклонено, чтобы
  не усложнять стабильный простой формат.
- Создать универсальный игровой движок: отложено до появления второго режима с
  теми же требованиями.
- Разрешить LLM выбирать процедуры: отклонено по соображениям безопасности.

## Consequences

Положительные:

- игровые назначения воспроизводимы и тестируются без LLM;
- одинаковое состояние доступно вебу и Android;
- новая модель или prompt не могут ослабить правила палаты;
- игровые данные восстанавливаются обычной миграцией и каталогом из Git.

Отрицательные:

- появляется отдельная таблица сессий и событий;
- каждый новый случай требует валидируемой конфигурации и теста;
- интерфейсам нужен специализированный экран.
