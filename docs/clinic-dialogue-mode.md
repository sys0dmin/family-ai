# Мини-диалоги и режим старшего врача

В палате Доктора Пульса интерфейс показывает короткую подсказку вместо длинной инструкции:

- до первого действия: «Что проверим сначала?»;
- после процедур: количество выполненных шагов и вопрос «Что сделаем дальше?»;
- после последнего действия: итог старшего врача.

Порядок действий остаётся свободным: ребёнок сам выбирает инструмент. Завершающее действие `call_senior` фиксирует полный осмотр и переводит карточку в состояние `completed`.
