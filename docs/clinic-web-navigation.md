# Навигация в веб-палате Доктора Пульса

После завершения осмотра кнопка «Новый пациент» возвращает к выбору карточек, не закрывая палату и не отправляя пользователя в обычный диалог. Завершённая карточка и сообщения остаются в истории.

Для активного осмотра кнопка «Завершить» сохраняет статус `left` и также показывает список пациентов. При повторном открытии палаты старый статус `left` не блокирует выбор нового случая.
