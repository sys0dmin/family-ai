# Family AI Mentor

## Архитектура MVP

### Цель

Family AI Mentor — домашний русскоязычный голосовой наставник для Леры, 6 лет. Он помогает учиться и исследовать мир, но не заменяет родителей, учителя или друзей.

Первый пользовательский сценарий — короткий безопасный голосовой диалог с Android-планшета в домашней сети. В том же браузерном интерфейсе доступен дополнительный текстовый режим; Matrix остаётся будущим транспортом.

## Зафиксированные решения

| Область | Решение |
| --- | --- |
| Пользователь | Один детский профиль: Лера, 6 лет, русский язык |
| Основной интерфейс | Визуальный детский PWA с голосовым и дополнительным текстовым режимом |
| Ввод | Push-to-talk, визуальные подсказки и опциональная клавиатура; постоянная запись и wake word не используются |
| Сеть | Только домашняя LAN; нет публичного DNS, проброса портов и внешнего доступа |
| AI | Внешние OpenAI API через заменяемый Provider interface |
| Хранилище | PostgreSQL на существующем Ceph (отдельный сервер 192.168.31.163) |
| История | Транскрипты и ответы — 10 дней; аудио не сохраняется |
| AI Gateway | Развернут на 192.168.31.173 |
| Родительский интерфейс | Защищённая админка: настройки, агенты, история, аналитика и состояние двух LXC проекта |
| Резервные копии | В MVP не создаются |

Ceph защищает рабочие данные от отказа отдельной ноды или диска в рамках текущего кластера. Он не является резервной копией и не защищает от логического удаления, ошибки конфигурации или отказа всего кластера.

## AI Gateway

Gateway — единственное место для бизнес-логики. Он:

- принимает голосовой или текстовый запрос;
- определяет профиль Леры и текущий диалог;
- применяет правила возрастной безопасности к входящему сообщению;
- собирает системные правила, конфигурацию агента и короткий контекст;
- вызывает STT, LLM и TTS через Provider interface;
- применяет правила безопасности к ответу;
- сохраняет транскрипт и ответ;
- обновляет агрегированную статистику;
- возвращает аудио либо текст ответного сообщения.

Gateway не содержит привязки к OpenAI SDK, Matrix или деталям веб-клиента.

### Транспортный API

Контракты будут версионироваться под `/v1` и описываться в OpenAPI.

| Endpoint | Назначение |
| --- | --- |
| `POST /v1/voice/turn` | Принять один аудиофрагмент и вернуть аудиоответ |
| `POST /v1/conversations/{conversation_id}/messages` | Сохранить одно сообщение |
| `POST /v1/conversations/{conversation_id}/turn` | Текстовый ход: принять сообщение и вернуть ответ AI |
| `POST /v1/voice/{conversation_id}/synthesize` | Озвучить готовую реплику голосом закреплённого агента |
| `GET /v1/agents` | Получить безопасные карточки доступных ребёнку агентов |
| `POST /v1/conversations/` | Создать диалог и закрепить выбранного агента и его текущую ревизию |
| `GET /healthz` | Проверка готовности сервиса |
| `GET /api/history/summary` | Защищённая сводка активности в Admin UI |
| `GET /api/history/conversations` | Защищённая история диалогов с поиском и пагинацией |
| `GET /api/agents` | Получить конфигурацию и историю версий агентов для родителя |
| `POST /api/agents/{id}/revisions` | Создать неизменяемую версию промпта личности |
| `POST /api/agents/{id}/revisions/{revision_id}/publish` | Опубликовать версию для новых диалогов |

`/v1/voice/turn` в MVP обрабатывает один полный ход: запись на планшете, загрузка, распознавание, ответ и синтез речи. Streaming можно добавить позднее без изменения доменной модели.

## Голосовой клиент

PWA отвечает только за пользовательский опыт:

- большую кнопку «Поговорить»;
- состояния «слушаю», «думаю», «отвечаю»;
- отправку записи после отпускания кнопки;
- воспроизведение аудиоответа;
- кнопку немедленной остановки ответа.

Он не хранит API-ключи, историю или правила безопасности. Доступ к микрофону требует HTTPS; локальный сертификат должен быть доверен на планшете.

## Агенты

Агенты являются версионной конфигурацией в PostgreSQL, а не Python-кодом.
Доступны «Учитель-друг», «Почемучка», «Сказочник», «Подумай сама» и «Нотка».

Его поведение:

- отвечает на русском короткими, понятными ребёнку фразами;
- объясняет через знакомые примеры и задаёт один наводящий вопрос за раз;
- не создаёт иллюзию, что он человек, единственный друг или замена взрослому;
- не просит скрывать что-либо от родителей;
- поощряет отдых, игру вне экрана и обращение к взрослому, когда это уместно.

Каждый диалог хранит `agent_id` и `agent_revision_id`. Публикация новой версии
влияет только на новые диалоги. Неизменяемая общая основа детской безопасности
остаётся в Gateway и компонуется с версионным промптом личности перед вызовом
провайдера. Детский API никогда не возвращает промпты или внутренние настройки.

Инструменты также являются конфигурацией агента. Gateway проверяет allowlist до вызова внешнего сервиса. Для «Нотки» голосовая запись параллельно проходит STT и заменяемый `MusicRecognitionProvider`. В историю попадает только транскрипт или нейтральная отметка о напеве; аудио не сохраняется.

## Безопасность ребёнка

Безопасность реализуется кодом и правилами Gateway, а не только промптом.

1. Входной фильтр проверяет персональные данные, опасные запросы и возрастные ограничения.
2. Агент получает возрастной контекст и ограничения ответа.
3. Выходной фильтр проверяет ответ перед передачей в TTS.
4. Для неподходящей темы система даёт короткий безопасный ответ и, при необходимости, предлагает обратиться к родителю.
5. Gateway ведёт структурированные технические логи без API-ключей, токенов и содержимого детских сообщений.

В MVP на детской странице нет PIN-кода или логина. Поэтому Gateway доступен только из доверенной домашней сети; любой пользователь этой сети сможет начать разговор от имени профиля Леры. Родительский интерфейс должен быть защищён отдельно.

## Данные и жизненный цикл

| Данные | Хранение | Срок |
| --- | --- | --- |
| Исходная аудиозапись | Не сохраняется после обработки | 0 дней |
| Распознанный текст и ответ | PostgreSQL | 10 дней |
| Краткосрочный контекст | PostgreSQL, выборка из истории | Не более 10 дней |
| Статистика по темам и активности | PostgreSQL, агрегированно | Дольше истории; без текста сообщений |

Планировщик Gateway ежедневно удаляет истёкшие сообщения. В MVP отсутствуют резервные копии, поэтому удалённые данные не восстанавливаются.

## Provider interface

Provider interface изолирует внешнего поставщика и предоставляет нормализованные операции:

- `transcribe_audio`;
- `generate_response`;
- `synthesize_speech`.

Входы и выходы операций используют собственные модели приложения, включая ошибки, идентификатор запроса, сведения об использовании и возможности провайдера. Gateway зависит только от этого интерфейса. Это позволяет позднее заменить OpenAI на локальные или иные совместимые реализации без изменения бизнес-логики.

Конфигурация разделена по возможностям: LLM и речевой контур могут обращаться к
разным OpenAI-совместимым endpoint и использовать разные ключи. Это необходимо,
когда выбранный LLM-провайдер поддерживает чат и STT, но не предоставляет TTS.
Разделение не выходит за границы provider adapter и не влияет на сервисы
диалога, безопасности и хранения.

## Развёртывание

Кластер Proxmox состоит из трёх нод с существующим Ceph. Для MVP не требуется разворачивать новые самостоятельные LXC для каждого технического компонента.

Рекомендуемое начальное размещение:

- LXC или VM `family-ai-app`: Gateway, reverse proxy и статические файлы PWA; 2 vCPU, 2–3 GB RAM;
- LXC или VM `family-ai-db`: PostgreSQL; 2 vCPU, 2 GB RAM;
- диски гостей размещаются на существующем Ceph;
- Redis и Matrix не разворачиваются, пока у них нет подтверждённой задачи.

Необходимо ограничить firewall: вход в Gateway — только из LAN, исходящий доступ — только к необходимым AI API и системным обновлениям.

## Будущие расширения

- Matrix adapter как дополнительный транспорт, без переноса бизнес-логики в бот;
- streaming голоса для уменьшения задержки;
- отдельные конфигурации агентов;
- настраиваемые родительские правила;
- локальные STT, TTS и LLM через Provider interface;
- vision и безопасный разбор изображений.
